# 3D coach figure: comparison with human reference images

Each exercise's 3D end position was put next to a picture of a person doing it and compared by eye. References: clinical illustrations from the American Academy of Orthopaedic Surgeons (OrthoInfo conditioning programmes) where one exists for the same exercise, otherwise photographs of people from Wikimedia Commons. Date: 2026-11-17.

Verdicts: **same** = same body position and outcome; **variant** = both are recognised versions and the 3D follows the app's own instruction text; **fixed** = a difference was found and corrected; **minor** = small difference, noted; **DIFFERENT** = still differs, open; **no equivalent / no usable reference** = the picture found was of something else; **not yet compared** = no reference image obtained yet.

Counts: not yet compared: 80, same: 41, variant: 6, no equivalent reference: 5, no usable reference: 3, DIFFERENT: 1, minor: 1, fixed: 1
